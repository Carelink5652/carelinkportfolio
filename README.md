# CareLink Portfolio

A premium responsive portfolio website for CareLink, a software development company.

## Project structure

- `index.html` — homepage
- `pages/` — supporting pages
- `style.css` — shared design system and layout styling
- `script.js` — navigation and reveal animations
- `js/` — contact and Supabase helpers
- `assets/` — branding and project visuals

## Notes

- The current site includes placeholder contact details and demo Supabase configuration values.
- Replace the sample values in `js/supabase.js` with your live Supabase project URL and anon key before deployment.
- Update the WhatsApp number and email if needed.
